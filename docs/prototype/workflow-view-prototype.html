原型：面板工作流视图

右上角切 宽 / 窄 面板宽度；面板顶部 任务卡视图 ⇄ 工作流视图 切换。
任务卡视图：现在的列表，一行一张票，按工作流分组 —— 这次不动它。
工作流视图：一条工作流一条泳道；票按 blockedBy 排成链，箭头 =「先做这个才能做那个」；三条工作流并列，各自可折叠。
  • 点卡片选中，底部出详情条（含验收项与阻塞来源）
  • 状态：已关闭 进行中 可做 被阻塞
  • 状态筛选与列表共用一套；切视图不丢筛选
  • 窄面板（330）下卡片自动换行、泳道可横向滑
顺序口径（落地时）：先按依赖拓扑，同层按票号升序，无依赖按编号。
