工作流视图：折叠 + 按工作流执行

要定的是三件事：折叠怎么让人知道里面还有货、「执行全部」放哪最顺手、一条泳道里信息怎么排。

  1. A · 现状基线：分层卡片 + 连线，折叠在泳道头，执行是头上一颗小按钮。
  2. B · 路线图：竖轨 + 站点，头部大 CTA，折叠后只剩「下一站」。
  3. C · 清单表：不画链，票排成表（状态 / 编号 / 标题 / 挡路），执行在工具条。

底部白色药丸：左右箭头 / 键盘 ← → 切变体；右边两档宽度（520 / 330）验证窄面板。

数据是编的，形状照真实快照：票号、状态、blockedBy、认领人。交互只做只读：点卡片=打开票（模拟）、点执行=注入任务书（模拟）。
